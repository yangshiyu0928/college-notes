3. 写出第一个交互程序：hello.py

## 踩过的坑（都是财富）

1. **装完 Python 命令行找不到命令** → 因为验证用的是安装前打开的旧 cmd 窗口；环境变量改了，旧窗口不知道。新开窗口就好。
2. **输 python 弹出微软商店** → Windows 商店的"应用执行别名"劫持，去 设置→应用→高级应用设置→应用执行别名 关掉。
3. **文件保存成 "hello py"（空格）而不是 hello.py（点）** → VS Code 认不出是 Python 文件，没有运行按钮。
4. **把 `python` 写进了代码第一行** → `python` 是命令行的启动命令，不是代码。
5. **print 的引号没闭合** → 引号有开必有合，全部用英文引号。

## 学到的命令

```
python --version    # 查看 Python 版本
python hello.py     # 在命令行运行一个脚本
```
